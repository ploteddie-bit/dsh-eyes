# DSH Eyes v2.1 — Activation solveur + debug canal extension (avec Eddie)

> **For agentic workers:** REQUIRED SUB-SKILL: subagent-driven-development. Steps use checkbox syntax.

**Goal:** Activer le solveur captcha local (qwen2.5-vl sur les 2 serveurs Ollama d'Eddie) et valider en conditions réelles le canal extension (worker MV3 + keep-alive) avec Eddie au navigateur.

**Architecture:** Tir SSH parallèle pour les pulls Ollama ; puis session interactive avec Eddie : chaque étape du cycle (goto → read → fill → click → solve) est exécutée via l'API v2 pendant qu'Eddie observe Chrome ; le comportement du keep-alive (worker MV3) est monitoré sur 10 min d'inactivité pour confirmer la WS permanente.

**Tech Stack:** SSH (serveur-ia, ia-general), Ollama API, démon DSH Eyes (127.0.0.1:8445), extension Chrome, journal events/actions.jsonl.

## Global Constraints

- Eddie est le juge visuel final pour tout ce qui s'affiche dans Chrome.
- Zéro modification de code pendant les tests live (sauf bug bloquant — alors STOP + arbitrage).
- Les pulls Ollama sont des téléchargements ~6 Go : les lancer en parallèle (2 serveurs distincts), vérifier l'intégrité (api/tags).
- Toute mesure (temps de solve, comportement keep-alive) est consignée dans `docs/test-e2e-2026-10-05.md` (append).

### Task 2: Validation live du canal extension avec Eddie (worker MV3 + keep-alive)

**Files:** append `docs/test-e2e-2026-10-05.md` (§8 — mesures live).

**Prérequis :** Eddie au navigateur, extension rechargée (fait à 01h04), démon v2 lancé.

- [ ] **Step 1:** Démarrer le démon et vérifier la WS extension :
```bash
~/.dsh-eyes/bin/dsh-eyes &   # ou target/debug/dsh-eyes (binaire v2 le plus récent)
sleep 3 && curl -s http://127.0.0.1:8445/health
```
- [ ] **Step 2:** Cycle réel 1 — goto (Eddie voit l'onglet s'ouvrir) :
```bash
TOKEN=$(cat ~/.dsh-eyes/token)
curl -s -m45 -X POST -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" \
  -d '{"cmd":"tabs_create","params":{"url":"https://www.pmu.fr/turf/r1/c1/"}}' http://127.0.0.1:8445/v2/cmd
```
Attendu : `{"ok":true,...}` + Eddie confirme l'onglet visible.
- [ ] **Step 3:** Cycle réel 2 — read avec tab_id explicite (contenu pmu.fr) :
```bash
curl -s -m35 -X POST -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" \
  -d '{"tab_id":<ID_DU_STEP2>}' http://127.0.0.1:8445/v2/read
```
Attendu : ok:true + texte du site (>1000 caractères).
- [ ] **Step 4:** Cycle réel 3 — fill + click sur un vrai champ (ex. recherche pmu.fr si présente, sinon page de démo) :

Attendu : {ok:true} ×2 + Eddie voit le champ se remplir char par char (frappe lognormale visible).
